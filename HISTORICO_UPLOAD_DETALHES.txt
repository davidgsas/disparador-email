🔄 FLUXO COMPLETO DO UPLOAD:
═══════════════════════════════════════════════════════════════════════

1️⃣  ENVIO DO LOTE
    • Sistema dispara email com relatório PDF
    • Link único gerado automaticamente
    • Status inicial: "📤 Link enviado ao prestador"

2️⃣  PRESTADOR RECEBE EMAIL
    • Email contém relatório em PDF (anexo)
    • Email contém link para upload da N.F.
    • Prestador clica no link

3️⃣  PRESTADOR FAZ UPLOAD
    • Abre página no sistema externo
    • Seleciona PDF da nota fiscal
    • Confirma envio
    • Sistema externo valida e armazena

4️⃣  CONSULTA (AUTOMÁTICA OU MANUAL)
    
    AUTOMÁTICA (Job - a cada hora):
    • Job consulta todos os lotes pendentes
    • Verifica status na API
    • Se disponível, baixa automaticamente
    • Atualiza banco de dados
    
    MANUAL (Usuário no histórico):
    • Usuário clica "Consultar Status"
    • Sistema verifica na API
    • Se disponível, baixa na hora
    • Atualiza tela automaticamente

5️⃣  N.F. RECEBIDA
    • Status muda para: "✅ N.F. RECEBIDA VIA UPLOAD"
    • Arquivo salvo em: uploads/nota_fiscal_lote_{id}.pdf
    • Botão de download disponível
    • Pode alterar status do lote para "N.F. RECEBIDA"

🎯 QUANDO USAR CADA FUNCIONALIDADE:
═══════════════════════════════════════════════════════════════════════

USE "Consultar Status" QUANDO:
• Precisa verificar urgentemente se prestador enviou
• Cliente pediu para confirmar recebimento
• Vai fazer pagamento e precisa da N.F.
• Nota: Job automático faz isso a cada hora!

USE "Copiar Link" QUANDO:
• Prestador perdeu o email original
• Precisa reenviar por WhatsApp/SMS
• Quer enviar para outra pessoa da empresa

USE "Baixar N.F." QUANDO:
• Precisa do arquivo para conferência
• Vai enviar para contabilidade
• Precisa anexar em outro sistema
• Fazer backup local
