class UploadAPIClient:
    
    def consultar_lote(self, lote_id):
        """Consulta status de um lote na API externa"""
        url = f"{self.base_url}/api/lotes/{lote_id}/status"
        
        response = requests.get(
            url,
            headers={"Authorization": f"Bearer {self.api_key}"},
            timeout=30
        )
        
        if response.status_code == 200:
            return True, response.json()
        elif response.status_code == 404:
            return False, {"message": "Lote não encontrado no sistema externo"}
        else:
            return False, {"message": f"Erro {response.status_code}"}
    
    def download_nota_fiscal(self, download_url, save_path):
        """Baixa a nota fiscal da URL fornecida pela API"""
        response = requests.get(
            download_url,
            headers={"Authorization": f"Bearer {self.api_key}"},
            timeout=60,
            stream=True
        )
        
        if response.status_code == 200:
            with open(save_path, 'wb') as f:
                for chunk in response.iter_content(chunk_size=8192):
                    f.write(chunk)
            return True, save_path
        else:
            return False, f"Erro ao baixar arquivo: {response.status_code}"

📋 ESPECIFICAÇÃO PARA O OUTRO DESENVOLVEDOR:
═══════════════════════════════════════════════════════════════════════

ENDPOINT NECESSÁRIO:
GET /api/lotes/{lote_id}/status

PARÂMETROS:
• lote_id (path): ID do lote no nosso sistema

HEADERS:
• Authorization: Bearer {API_KEY}

RESPONSE (JSON):

Quando ainda não enviado:
{
  "lote_id": 123,
  "status": "pending",
  "message": "Aguardando upload do prestador"
}

Quando já enviado:
{
  "lote_id": 123,
  "status": "completed",
  "nota_fiscal": {
    "filename": "nota_fiscal_lote_123.pdf",
    "download_url": "https://api-externa.com/files/abc123xyz789.pdf",
    "uploaded_at": "2025-10-14T10:30:00Z",
    "file_size": 245678,
    "content_type": "application/pdf"
  }
}

Quando expirado (30 dias):
{
  "lote_id": 123,
  "status": "expired",
  "message": "Link de upload expirou"
}

Quando lote não existe:
{
  "error": "Lote não encontrado",
  "lote_id": 999
}

SEGURANÇA:
• Validar API Key no header
• Retornar 401 se não autorizado
• Retornar 404 se lote não existe
• Rate limiting recomendado
