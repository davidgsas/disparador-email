⚡ USO
═══════════════════════════════════════════════════════════════════

FLUXO NORMAL:
1. Enviar lote → Email sai com PDF
2. Sistema envia para API automaticamente
3. Link gerado e salvo
4. Prestador acessa e faz upload

REENVIO MANUAL:
1. Histórico > Expandir lote
2. Clicar "Enviar para API Agora" (se não foi)
   OU "Reenviar" (se expirou)
3. Novo link gerado
