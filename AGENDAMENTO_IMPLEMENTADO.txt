🎯 OPÇÕES DE AGENDAMENTO PRÉ-DEFINIDAS:
───────────────────────────────────────────────────────────────────────

1. 🌅 Diário às 3h da manhã          → 0 3 * * *
2. ⏰ A cada 6 horas                 → 0 */6 * * *
3. 🕐 A cada 12 horas                → 0 */12 * * *
4. 📅 Toda segunda-feira às 2h      → 0 2 * * 1
5. 🌙 Todo domingo às 23h            → 0 23 * * 0
6. ⚡ De hora em hora                → 0 * * * *
7. ⚙️ Personalizado                  → Digite sua expressão

🔧 COMO USAR:
───────────────────────────────────────────────────────────────────────

1. Iniciar o sistema:
   $ streamlit run streamlit_app.py

2. Navegar até:
   🗄️ Backups do Banco → ⚙️ Configurações

3. Na seção "🤖 Agendamento Automático de Backup":
   • Escolher frequência
   • Clicar em "💾 Salvar Agendamento"
   • Aguardar confirmação

4. Verificar agendamento:
   $ crontab -l | grep "Backup Disparador Email"

5. Monitorar execuções:
   $ tail -f backups/backup.log

🆘 TROUBLESHOOTING:
───────────────────────────────────────────────────────────────────────

Problema: Agendamento não aparece
Solução: $ crontab -l (verificar se foi adicionado)

Problema: Backup não executa
Solução: 
  1. Testar manualmente: ./backup_auto.sh
  2. Verificar permissões: ls -l backup_auto.sh
  3. Ver log: tail backups/backup.log

Problema: Erro ao salvar
Solução: Verificar permissões do crontab: crontab -e
