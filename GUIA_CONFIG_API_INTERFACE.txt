🎬 COMO USAR:
═══════════════════════════════════════════════════════════════════════

PASSO 1: Receber Credenciais
─────────────────────────────
1. Entre em contato com o desenvolvedor do sistema externo
2. Ele fornecerá:
   • URL da API: https://api-externa.novomundo.com.br
   • API Key: nmrj_2K8dP9mN3qR7sT1vW5xY4zA6bC0eF2gH8jK3mL9nP1qR5sT7vW0xY4zA6

PASSO 2: Acessar Interface
───────────────────────────
1. Abra o Streamlit
2. No menu lateral, clique em "📤 Upload de Notas Fiscais"
3. Clique na tab "⚙️ Configurações"

PASSO 3: Preencher Formulário
──────────────────────────────
1. Cole a URL no campo "🔗 URL da API"
   Exemplo: https://api-externa.novomundo.com.br

2. Cole a API Key no campo "🔑 API Key"
   Exemplo: nmrj_2K8dP9mN3qR7sT1vW5xY4zA6bC0eF2gH8jK3mL9nP1qR5sT7vW0xY4zA6

3. Se quiser ver a API Key enquanto digita:
   ☑ Marque "Mostrar API Key"

4. Clique em [💾 Salvar Configurações]

PASSO 4: Confirmação
─────────────────────
✅ Configurações salvas com sucesso!
🔄 Recarregando variáveis de ambiente...

→ Página recarrega automaticamente
→ Status muda para: ✅ API Configurada!

🔐 SEGURANÇA:
═══════════════════════════════════════════════════════════════════════

✅ API Key mascarada por padrão
   • Mostra apenas: nmrj**********************v
   • Primeiros 4 e últimos 4 caracteres
   • Proteção contra olhares curiosos

✅ Campo tipo password
   • Digite sem que apareça na tela
   • Só mostra ●●●●●●●●●●●
   • Marque checkbox para ver

✅ Salvo em .env
   • Arquivo local, não vai para Git (.gitignore)
   • Não fica em banco de dados
   • Fácil de fazer backup

✅ Recarregamento automático
   • Não precisa reiniciar aplicação
   • load_dotenv(override=True)
   • Valores atualizados imediatamente

💾 ONDE É SALVO:
═══════════════════════════════════════════════════════════════════════

Arquivo: .env (na raiz do projeto)

Formato:
┌──────────────────────────────────────────────────────────────────┐
│ UPLOAD_API_URL="https://api-externa.novomundo.com.br"           │
│ UPLOAD_API_KEY="nmrj_2K8dP9mN3qR7sT1vW5xY4zA6bC0eF2gH8jK3mL"   │
└──────────────────────────────────────────────────────────────────┘

Outras variáveis no .env são preservadas:
• CLIENT_ID
• TENANT_ID
• DB_HOST
• DB_USER
• etc.

💡 DICAS:
═══════════════════════════════════════════════════════════════════════

✓ Cole diretamente do email que recebeu as credenciais
✓ Não adicione espaços no início ou fim (sistema remove automaticamente)
✓ URL não precisa ter "/" no final (sistema remove se tiver)
✓ Use "Mostrar API Key" só quando necessário
✓ Teste a conexão após configurar
✓ Se mudar as credenciais, só preencher novamente e salvar

⚠️ TROUBLESHOOTING:
═══════════════════════════════════════════════════════════════════════

PROBLEMA: Salvei mas ainda diz "não configurada"
SOLUÇÃO: Aguarde 1 segundo, página deve recarregar automaticamente

PROBLEMA: API Key aparece incompleta
SOLUÇÃO: Normal! É mascarada por segurança. Marque "Mostrar API Key" se precisar ver

PROBLEMA: Teste de conexão falha
SOLUÇÃO: 
1. Verifique URL (deve ser HTTPS)
2. Verifique API Key (copie novamente)
3. Confirme com desenvolvedor externo se está ativa

PROBLEMA: Quero editar .env manualmente
SOLUÇÃO: Pode! Mas use a interface, é mais fácil e seguro

PROBLEMA: Perdi a API Key
SOLUÇÃO: Entre em contato com desenvolvedor do sistema externo
