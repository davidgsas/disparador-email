🔄 FLUXO COMPLETO
═══════════════════════════════════════════════════════════════════

1️⃣ Sistema cria lote
   └─ Salva no banco local

2️⃣ Sistema envia para API DV
   └─ POST com dados do lote
   └─ Recebe link único

3️⃣ Link salvo no banco
   └─ Campo: link_upload

4️⃣ Template renderizado
   └─ {{link_upload}} substituído pelo link real

5️⃣ Email enviado
   └─ Com PDF anexo
   └─ Com link no corpo

6️⃣ Prestador recebe
   └─ Vê relatório em PDF
   └─ Clica no link
   └─ Anexa nota fiscal

═══════════════════════════════════════════════════════════════════

⚠️ CENÁRIOS
═══════════════════════════════════════════════════════════════════

CENÁRIO 1: Tudo OK ✅
─────────────────────────────────────────────────────────────────
• API responde
• Link gerado
• Email sai COM link
• Prestador acessa e anexa NF

CENÁRIO 2: API Fora do Ar ⚠️
─────────────────────────────────────────────────────────────────
• API não responde
• Link não gerado
• Email sai SEM link (msg alternativa)
• Job automático tentará depois (1 hora)
• Ou enviar link manualmente depois

CENÁRIO 3: Link Expirado ⏰
─────────────────────────────────────────────────────────────────
• Prestador demorou +30 dias
• Link não funciona mais
• Reenviar: Histórico > "Reenviar para API"
• Novo link gerado
• Copiar e enviar por WhatsApp/Email
