🔄 FLUXO DE USO:
═══════════════════════════════════════════════════════════════════════

CENÁRIO 1: Verificar se prestador enviou a nota fiscal
───────────────────────────────────────────────────────
1. Acesse "📤 Upload de Notas Fiscais"
2. Encontre o lote na lista
3. Expanda "Ver Detalhes"
4. Clique em [🔄 Consultar Status Agora]
5. Aguarde... Sistema verifica na API
6. Se disponível:
   → Status muda para ✅
   → Arquivo baixado automaticamente
   → Botão [⬇️ Baixar N.F.] fica ativo

CENÁRIO 2: Reenviar link de upload ao prestador
────────────────────────────────────────────────
1. Localize o lote
2. Expanda "Ver Detalhes"
3. Clique em [📋 Copiar Link]
4. Link aparece na tela
5. Copie (Ctrl+C) e envie ao prestador via:
   • WhatsApp
   • Email
   • SMS

CENÁRIO 3: Gerar relatório Excel de uploads
────────────────────────────────────────────
1. Vá para TAB "Histórico Completo"
2. Visualize todos os uploads na tabela
3. Clique em [📊 Exportar para Excel]
4. Arquivo baixado: historico_uploads_YYYYMMDD.xlsx

CENÁRIO 4: Configurar pela primeira vez
────────────────────────────────────────
1. Acesse TAB "Configurações da API"
2. Se ver ⚠️ amarelo:
   
   a) Edite arquivo .env:
      $ nano .env
      
   b) Adicione:
      UPLOAD_API_URL="https://api-externa.com"
      UPLOAD_API_KEY="sua-chave-aqui"
      
   c) Salve e reinicie Streamlit:
      $ streamlit run streamlit_app.py

3. Volte à interface
4. Clique [🚀 Testar Conexão]
5. Se ✅ verde: Pronto para usar!

🎯 CÓDIGOS DE STATUS:
═══════════════════════════════════════════════════════════════════════

⏳ PENDENTE (pending)
   → Prestador ainda não enviou a nota fiscal
   → Link ativo, aguardando upload
   → Ações: Consultar status, Reenviar link

✅ COMPLETO (completed)
   → Nota fiscal recebida com sucesso!
   → Arquivo baixado e salvo
   → Ações: Baixar arquivo, Ver detalhes

⏰ EXPIRADO (expired)
   → Link expirou (30 dias)
   → Prestador não enviou a tempo
   → Ações: Gerar novo link (manual)

❌ FALHA (failed)
   → Erro no processo de upload
   → Verificar logs para detalhes
   → Ações: Reenviar, Contatar suporte

🔧 AÇÕES DISPONÍVEIS:
═══════════════════════════════════════════════════════════════════════

[🔄 Consultar Status Agora]
   • Verifica na API externa se arquivo foi enviado
   • Atualiza status no banco de dados
   • Se disponível, baixa arquivo automaticamente
   • Mostra resultado instantâneo

[⬇️ Baixar N.F.]
   • Disponível apenas se arquivo já foi recebido
   • Baixa PDF da nota fiscal
   • Arquivo salvo em: uploads/nota_fiscal_lote_{id}.pdf

[🔗 Reenviar Link]
   • Mostra o link único de upload
   • Permite copiar para compartilhar
   • Útil se prestador perdeu o email

[📋 Copiar Link]
   • Exibe link em caixa de código
   • Fácil de copiar (Ctrl+C)
   • Link formato: https://api.com/upload/{token}

[🚀 Testar Conexão]
   • Verifica se API está acessível
   • Testa autenticação (API Key)
   • Retorna sucesso ou erro

[📊 Exportar para Excel]
   • Gera planilha com histórico completo
   • Colunas: Lote, Prestador, Período, Status, Valor
   • Nome: historico_uploads_YYYYMMDD_HHMMSS.xlsx

💡 DICAS DE USO:
═══════════════════════════════════════════════════════════════════════

Performance:
✓ Use filtros para encontrar lotes rapidamente
✓ Ordene por "Mais Recentes" para ver últimos envios
✓ Consulta manual só quando necessário (job faz automaticamente)

Segurança:
✓ API Key sempre mascarada na interface
✓ Links únicos por lote (token exclusivo)
✓ Expiração automática após 30 dias

Organização:
✓ Exporte relatórios mensalmente
✓ Arquive notas fiscais antigas
✓ Mantenha backup da pasta uploads/

Troubleshooting:
✓ Status não atualiza? → Verifique conexão API
✓ Arquivo não baixa? → Verifique permissões uploads/
✓ Link não funciona? → Verifique se não expirou

🤖 JOB AUTOMÁTICO:
═══════════════════════════════════════════════════════════════════════

O que faz:
• Executa a cada hora (configurável)
• Consulta todos os lotes pendentes
• Verifica status na API
• Baixa arquivos disponíveis automaticamente
• Atualiza banco de dados
• Gera log de execução

Como configurar:
┌──────────────────────────────────────────────────────────────┐
│ $ crontab -e                                                  │
│                                                               │
│ # Adicionar esta linha (executa a cada hora):                │
│ 0 * * * * cd /caminho/projeto && source .venv/bin/activate &&│
│   python job_consultar_notas.py >> logs/consulta_notas.log   │
└──────────────────────────────────────────────────────────────┘

Verificar se está ativo:
┌──────────────────────────────────────────────────────────────┐
│ $ crontab -l                                                  │
└──────────────────────────────────────────────────────────────┘

Ver logs:
┌──────────────────────────────────────────────────────────────┐
│ $ tail -f logs/consulta_notas.log                            │
└──────────────────────────────────────────────────────────────┘
