╔════════════════════════════════════════════════════════════════════════╗
║  🎯 FLUXO DO SISTEMA                                                   ║
╚════════════════════════════════════════════════════════════════════════╝

1️⃣  DISPARO DO LOTE
    └─ Sistema cria lote com OS
    └─ Chama API externa para criar link único
    └─ Salva token e URL no banco

2️⃣  ENVIO DO EMAIL
    └─ Email inclui relatório PDF (anexo)
    └─ Email inclui link para upload
    └─ Link é único e expira em 30 dias

3️⃣  PRESTADOR FAZ UPLOAD
    └─ Clica no link recebido
    └─ Abre página no sistema externo
    └─ Seleciona PDF da nota fiscal
    └─ Sistema externo valida e armazena

4️⃣  CONSULTA AUTOMÁTICA
    └─ Job roda a cada hora (cron)
    └─ Consulta status na API externa
    └─ Se arquivo disponível, baixa automaticamente
    └─ Salva em uploads/ e atualiza banco

5️⃣  ARQUIVO RECEBIDO
    └─ Status do lote: "N.F. RECEBIDA"
    └─ Arquivo disponível no histórico
    └─ Pode ser baixado pela interface
